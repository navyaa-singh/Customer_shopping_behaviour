# Customer_shopping_behaviour

The goal of this project is to analyze a retail company’s consumer shopping behavior data to understand how customers make purchasing decisions. The analysis focuses on identifying patterns across customer demographics, product categories, sales channels (online vs. offline), discounts, seasons, reviews, and payment preferences.

#TASK 1 : Data Immersion and Wrangling
In this task, I focused on understanding and preparing the consumer shopping behavior dataset for analysis. I explored the dataset to understand its structure, variables, and business relevance, and documented this information in a detailed data dictionary.
I then performed an initial data quality assessment to identify missing values, duplicates, inconsistent formats, and potential outliers. Based on these findings, I cleaned and transformed the data using Python (Pandas), including standardizing formats and creating derived features where required.
The final output of this task is a clean, well-structured, analysis-ready dataset, along with documented cleaning scripts, forming a strong foundation for exploratory data analysis and business insights in the next stages of the internship.
