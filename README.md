# Customer_shopping_behaviour - TASK 2 - EDA AND BUSINESS INTELLIGENCE

This task focuses on performing Exploratory Data Analysis (EDA) and Business Intelligence on a cleaned customer shopping dataset.

The goal was to extract actionable insights using descriptive statistics, SQL queries, and multivariate analysis.

**Key Analysis Performed**
1.Descriptive Statistics
2.Revenue Trend Analysis
3.Top Products & Categories
4.Regional Performance Analysis
5.Customer Retention Analysis
6.Correlation Study
7.KPI Dashboard Design

**Tools Used**
1.Python (Pandas, Matplotlib, Seaborn)
2.SQL
3.Excel / PowerPoint (Dashboard)

**Key Insights**
1.Identified top revenue-generating products
2.Analyzed monthly revenue trends
3.Evaluated customer repeat rate
4.Discovered key revenue drivers
